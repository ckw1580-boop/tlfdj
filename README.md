# 电气控制系统仿真软件（Unity 离线复刻）

本项目是在 Unity 2022.3.62f3c1 中对“电气控制系统仿真软件”核心实训功能的离线复刻。视觉、模型、端子位置和交互以原始 Windows 程序的实际运行画面为基准，说明书与配置文件只用于补充理解。

程序跳过登录，启动后直接进入电气实训室。账号、在线更新、云端考试、真实 PLC、S7/Modbus 和原竞赛平台接口不属于离线版本范围。

## 当前能力

- 使用 Built-in Render Pipeline，启动场景为 `Assets/Scenes/ElectricalTraining.unity`。
- 使用原 `Experiment` 实训室、电控柜、设备、端子排、材质、贴图和 UI 资源。
- 支持视角、拖动、接线、仿真、排故五种互斥模式。
- 支持接线视角（柜体全景）和排故视角（柜体正面近景）。
- 支持电线、跳线、端子吸附、折点、颜色、线径、删除、撤销和恢复。
- 支持端子悬停提示：深灰提示框、白色端子名、黄色引线指向实际吸附中心。
- 支持端子排黄色分区备注，标明三相电源、指示灯、旋钮/按钮、PLC、中间继电器、变频器、接触器、FR/KT 等端子区域。
- 提供三相电源、断路器、按钮、旋钮、指示灯、接触器、热继电器、时间继电器、电机等离散电气行为。
- 提供万用表、验电笔/探针、示波器和转速表，测量数据来自同一仿真快照。
- 包含 10 项三相异步电动机控制实训及拓扑、动作序列联合验收。
- 包含 A–D 本地考试包、故障注入、计时、评分、结果保存和虚拟 PLC。
- 兼容原版 `.cc3d` 的 `element`、`customPoints`、`line`、`ropeLine` 四个根结构，并保留未知字段。
- 截图、会话、成绩、考试进度和录屏帧序列均保存到本机，不产生业务网络请求。

## 原始素材接入

仓库内已有原始内容时可直接打开项目。需要重新导入资源时：

1. 将包含完整 `.meta` 文件的原 `Assets` 子集放到项目根目录 `OriginalAssetsSource/`。
2. 在 Unity 菜单执行 `Electrical Sim > Import Original Assets`。
3. 导入器将资源整理到 `Assets/OriginalContent/`，并创建或更新 `OriginalVisualRegistry.asset`。
4. 自动识别失败的 Prefab 可在注册表中按 `DeviceId` 或 `TypeId` 指定。

不要删除原资源的 `.meta` 文件；Prefab、材质、贴图和端口 Transform 依赖原 GUID 关系。

## 启动与构建

### Unity 编辑器

1. 用 Unity Hub 添加本项目目录。
2. 使用 Unity 2022.3.62f3c1 打开项目。
3. 打开 `Assets/Scenes/ElectricalTraining.unity`。
4. 点击 Play，程序直接进入实训场景。

### Windows x64

在 Unity 菜单执行：

```text
Electrical Sim > Build Windows x64
```

默认输出为：

```text
Build/Windows/ElectricalTraining.exe
```

构建产物可断网启动；不需要原始 EXE、原 `App.dll` 或真实 PLC 服务。

## 操作说明

### 模式

| 快捷键 | 模式 | 说明 |
| --- | --- | --- |
| `1` | 视角 | 浏览场景和切换预设视角 |
| `2` | 拖动 | 选择并拖动允许移动的器件 |
| `3` | 接线 | 连接端子、编辑和删除线路 |
| `4` | 仿真 | 操作按钮、断路器和保护器并观察电路状态 |
| `5` | 排故 | 使用机柜正面近景、故障和测量工具 |
| `Esc` | 视角 | 返回视角模式 |

### 相机

- `W/A/S/D`：平移。
- `Q/E`：下降/上升。
- 按住鼠标右键：旋转视角。
- 鼠标滚轮：缩放。
- 工具栏“接线视角”：机柜、端子和器件的全景布局。
- 工具栏“排故视角”：机柜居中、接近原软件构图的正面近景。

### 接线

- 在接线模式中依次点击两个可见端子完成连接。
- `Delete` 删除当前选中或最近一条线路。
- `Ctrl+Z` / `Ctrl+Y` 撤销或恢复。
- 上端子排保持原始上侧物理锚点，下端子排使用下侧锚点；切换线型或视角时两者都不会翻转到另一侧。
- 鼠标停留在端子上会显示配置中的语义名称，例如 `SB8_COM2`、`KA6_8`、`KM1_53NO`。
- 提示 UI 不阻挡端子点击、测量和接线射线。

## 电气仿真

离散电气图以端口和导电关系为基础，每帧迭代到稳定状态，包含：

- 三相电源和相序；
- 断路器、熔断器；
- 常开/常闭按钮与触点；
- 接触器线圈、主触点、辅助触点、自锁和互锁；
- 时间继电器延时触点；
- 热继电器和过载状态；
- 电机正转、反转、停止与制动；
- 短路、断路和非法反转检查。

任务提交先比较规范化网络拓扑，再执行规定按钮序列验证接触器、保护器和电机行为，避免仅按线路数量评分。

## 十项实训

离线任务覆盖：

1. 单点启动；
2. 点动控制；
3. 自锁控制；
4. 过载保护自锁；
5. 联锁正反转；
6. 两地/多地控制；
7. 时间控制；
8. 顺序启动；
9. 反接制动；
10. 能耗制动。

## 仪表与排故

- 万用表：交流/直流电压、电阻和通断采样。
- 验电笔/探针：从选中端口读取电势。
- 示波器：读取仿真快照中的周期信号。
- 转速表：读取电机方向和转速状态。
- 排故模式使用柜体正面近景，并保留端子悬停、接线位置和测量功能。

## 本地考试与虚拟 PLC

- `F5`、`F6`、`F7`、`F8` 分别进入 A、B、C、D 本地考试包。
- 支持 WiringSubject、DebugSubject、FaultSubject、FaultWiring 和考试时间配置。
- 支持本地计时、故障注入、操作记录、分项评分、总分与结果恢复。
- PLC/IO 由 `LocalPlcRuntime` 在本地模拟扫描周期和内部触点。
- 不加载 `GXTcp`、`NetToPLCsim`、S7、Modbus 或其他外部通信服务。

## `.cc3d` 兼容

读写器保留以下四个根结构：

```text
element
customPoints
line
ropeLine
```

设备 GUID、类型、端口、折点、颜色、线径及无法识别的扩展字段会在读取和保存过程中保留。旧存档缺少新增物理锚点字段时会按兼容规则恢复。

## 本地数据

默认存档位置：

```text
文档/电气控制系统仿真软件/
```

该目录用于保存 `.cc3d`、会话、考试进度、成绩、截图和录屏帧序列。打开和导出存档使用 Windows 本地文件选择流程。

## 测试与验收

测试位于：

```text
Assets/ElectricalSim/Tests/EditMode/
Assets/ElectricalSim/Tests/PlayMode/
```

主要覆盖：

- 十项电路的正确接线、缺线、错线、短路、过载、互锁、定时、反转和制动；
- `.cc3d` 读取、保存、再读取的字段保真；
- 五种模式、视角切换、器件操作、接线、仪表、任务、考试和恢复；
- `DuanZiPai_0`–`DuanZiPai_4`、`DuanZiPai_6`–`DuanZiPai_8` 端子数量、名称、物理锚点和逻辑节点；
- 端子排黄色分区备注的文字内容、正面可见性、屏幕范围、字体方向和尺寸一致性；
- 电线/跳线锚点切换与悬停提示；
- M1、M2 电机模型六个原始绕组触点的位置与可见性；
- 1920×1080 基准截图及其他 16:9 分辨率布局。

测试和构建日志输出到 `Build/Reports/`。端子位置验收目标为世界坐标误差不超过 0.5 mm、1920×1080 下吸附中心屏幕误差不超过 2 px。

## Git 与大文件

模型、贴图、音视频和构建资源可能超过普通 Git 文件的合理大小。提交前请确认 Git LFS 已安装并检查 GitHub 单文件 100 MB 限制：

```powershell
git lfs install
git lfs status
git status
```

是否提交或推送由当前维护者决定；开发和测试过程不会自动执行 Git 提交或推送。

## 离线边界

以下功能明确不实现：

- 账号登录和身份验证；
- 联网更新和热更新；
- 云端考试、云端成绩和竞赛平台接口；
- 真实 PLC、S7、Modbus 和其他现场总线通信；
- 依赖原 EXE 或原 `App.dll` 才能运行的逻辑。

原资源确实缺失或损坏时应记录为阻塞项，不使用近似素材冒充像素级复刻结果。

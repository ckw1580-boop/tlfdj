# 电气控制系统仿真软件（Unity 离线复刻）

本项目是在 Unity 2022.3.62f3c1 中对“电气控制系统仿真软件”核心实训功能的离线复刻。视觉、模型、端子位置和交互以原始 Windows 程序的实际运行画面为基准，说明书与配置文件只用于补充理解。

程序跳过登录，启动后直接进入电气实训室。默认离线运行；可手动连接西门子 S7-1200、S7-1500 进行 PLC 联动。账号、在线更新、云端考试、Modbus 和原竞赛平台接口不属于当前范围。

## 当前能力

- 使用 Built-in Render Pipeline，启动场景为 `Assets/Scenes/ElectricalTraining.unity`。
- 使用原 `Experiment` 实训室、电控柜、设备、端子排、材质、贴图和 UI 资源。
- 支持视角、拖动、接线、仿真、排故五种互斥模式。
- 支持接线视角（柜体全景）和排故视角（柜体正面近景）。
- 支持电线、跳线、端子吸附、固定柜面折点、导线选中高亮、节点编辑、删除、撤销和恢复。
- 导线主体固定在创建时的柜面内，两端通过短引线连接真实端子；移动镜头或切换视角不改变已有线路，遮挡按场景深度处理，存档保留布线所在柜面。
- 背面布线平面取自 `DQG11` 安装板的实际网格和旋转，向外偏移 3 mm；不能使用 `DQG01` 整柜的世界包围盒代替背板，否则会因柜体旋转和底座突出而将导线放到柜外。
- KMF、KM1、KMR、FR 背面导线保留真实连接点位置，以立体细管向外引出并绕过器件边缘（间距 10 mm），中段贴柜面。预览和成品共用路径，自动引出段不保存为用户折点。
- 背面跳线模式下，FR 的 2T1／4T2／6T3（FR.T1／T2／T3）与电机之间也使用立体软跳线，忽略旧柜面折点；普通电线仍使用上述柜面布线规则。
- 选中导线后左下角显示只读属性：原色块、颜色名称（自定义色为十六进制值）、起点及终点的器件名称与端子标注。普通提示不覆盖属性，错误提示仍可见；取消选择后恢复最新状态提示。
- 跳线模式下连接电机端子排 `DuanZiPai_7` 与电机端子，始终生成固定在真实端点的立体软跳线；下垂量为端点距离的 15%（上限 15 cm），切回电线模式仍显示。接线过程的空白点击和旧存档中的柜面折点不影响此类跳线路径；其他导线保持原折点规则。自动软线可选择、删除和撤销，但不能插入曲线采样点。
- 支持端子悬停提示：深灰提示框、白色端子名、黄色引线指向实际吸附中心。
- 支持端子排黄色分区备注，标明三相电源、指示灯、旋钮/按钮、PLC、中间继电器、变频器、接触器、FR/KT 等端子区域。
- 排故视角在柜体原有 `DuanZiPai_5` 上提供 SB1–SB3 的 12 个连接点及“按钮（SB）端子区”备注，不生成重复模型。
- 柜体背面 SB1–SB3 与正面同名按钮共用触点状态，使用相同的 3 mm、0.1 秒按压回弹动画；点击可查看状态、常开/常闭触点和 `DuanZiPai_5.a1–a12` 连接点属性，仿真时按下操作、松手复位。
- 提供三相电源、断路器、按钮、旋钮、指示灯、接触器、热继电器、时间继电器、电机等离散电气行为。
- 提供万用表、验电笔/探针、示波器和转速表，测量数据来自同一仿真快照。
- 包含 10 项三相异步电动机控制实训及拓扑、动作序列联合验收。
- 包含 A–D 本地考试包、故障注入、计时、评分、结果保存和虚拟 PLC。
- 兼容原版 `.cc3d` 的 `element`、`customPoints`、`line`、`ropeLine` 四个根结构，并保留未知字段。
- 截图、会话、成绩、考试进度和录屏帧序列均保存到本机；仅用户主动连接 PLC 时启动 S7 通信。
- 场景 PLC_1、PLC_2 支持独立属性、60 个端子关联、逐点 M/Q/DB 位映射和真实 S7-1200/S7-1500 双向联动；非仿真模式只读，断网后手动重连。PLC 配置随 `.cc3d` 保存，详见 [PLC 联调说明](Docs/PLC联调说明.md)。

## 原始素材接入

仓库内已有原始内容时可直接打开项目。需要重新导入资源时：

1. 将包含完整 `.meta` 文件的原 `Assets` 子集放到项目根目录 `OriginalAssetsSource/`。
2. 在 Unity 菜单执行 `Electrical Sim > Import Original Assets`。
3. 导入器将资源整理到 `Assets/OriginalContent/`，并创建或更新 `OriginalVisualRegistry.asset`。
4. 自动识别失败的 Prefab 可在注册表中按 `DeviceId` 或 `TypeId` 指定。

不要删除原资源的 `.meta` 文件；Prefab、材质、贴图和端口 Transform 依赖原 GUID 关系。

## 启动与构建

### Unity 编辑器

1. 用 Unity Hub 添加本项目目录。
2. 使用 Unity 2022.3.62f3c1 打开项目。
3. 打开 `Assets/Scenes/ElectricalTraining.unity`。
4. 点击 Play，程序直接进入实训场景。

### Windows x64

在 Unity 菜单执行：

```text
Electrical Sim > Build Windows x64
```

默认输出为：

```text
Build/Windows/ElectricalTraining.exe
```

构建产物可断网启动；不需要原始 EXE、原 `App.dll` 或真实 PLC 服务。

### 模式

| 快捷键 | 模式 | 说明 |
| --- | --- | --- |
| `1` | 视角 | 浏览场景和切换预设视角 |

| `3` | 接线 | 连接端子、编辑和删除线路 |
| `4` | 仿真 | 操作按钮、断路器和保护器并观察电路状态 |

### 相机

- `W/A/S/D`：平移。
- `Q/E`：下降/上升。
- 按住鼠标右键：旋转视角。
- 鼠标滚轮：缩放。
- 工具栏“接线视角”：机柜、端子和器件的全景布局。
- 工具栏“排故视角”：机柜居中、接近原软件构图的正面近景。

### 接线

- 在接线模式中先点击起始端子；电线会随鼠标实时预览。
- 左键点击空白位置可连续添加路径点，再点击另一个端子完成连接；生成后的电线会平滑经过这些路径点。
- 再次点击起始端子可取消当前接线。
- 左键点击 KA1–KA6 中间继电器、正面 KM1–KM4 或背部 KM1–KM3 交流接触器、FR1–FR3 热继电器本体，在共用的左侧 280×240 浮窗查看白底黑色符号原理图；点击不同器件切换标题和图纸，保留接线起点和路径点。窗口外可继续接线，点击“关闭”或离开接线模式收起图纸。
- 单击已有导线可选中并显示黄色高亮和路径节点；拖动节点可在柜面上调整导线路径。
- 双击导线线段可在点击位置新增路径节点。
- `Delete` 删除当前选中或最近一条线路。
- 已选中路径节点时，`Delete` 优先删除该节点，再次按下才会删除整条导线。
- `Ctrl+Z` / `Ctrl+Y` 撤销或恢复。
- 导线和接线预览固定在电气柜表面：接线视角使用正面布线层，排故视角使用背面布线层，两个平面都不会随相机移动或旋转改变位置。
- 上端子排保持原始上侧物理锚点，下端子排使用下侧锚点；切换线型或视角时两者都不会翻转到另一侧。
- 鼠标停留在端子上会显示配置中的语义名称，例如 `SB8_COM2`、`KA6_8`、`KM1_53NO`。
- 提示 UI 不阻挡端子点击、测量和接线射线。

### 电机独立运行与端子短接

安装位 38、49、107、118 分别绑定 M1、M2、M3、M_DOUBLE，各自拥有独立运行状态、转子动画和测速读数。切换正背面视角不会改变电机端子的归属。电机端子排 A、B、C 组是独立的转接端子，不再自动连接任何电机；每个端子的上下锚点仍属于同一节点，必须用实际跳线连接到所需电机。旧实训中的 KB/KMB 制动控制只作用于 M1。

同一电机的端子短接线沿真实端点连接，向接线盒外侧拱起，不投影到控制柜表面。外接及跨电机跳线采用空间软线；短接预览、成线和存档重开使用同一路径规则，旧文件中的错误柜面折点不影响显示。

`.cc3d` 格式不变。旧 `M1.*` 端点统一对应安装位 38，不再同步驱动安装位 107；此前在 107 接线但保存为 M1 的线路，需要重新接到 M3。若旧文件只接到了电机端子排、没有接到电机本体，需要补接实际跳线。不会自动复制接线或恢复旧的隐式供电。

## 电气仿真

### 面板按钮、旋钮与 DC 24V 指示灯

原柜面上的钥匙、急停、总启动、总停止、HL1–HL6、SA1–SA2、SB1–SB8 共 20 个元件现在绑定到实际模型和运行时电路。进入“仿真”模式后，先开启钥匙，再按总启动送电。总停止、关闭钥匙或按急停会取消总供电；急停再次点击旋转复位后，仍需重新按总启动。初始及重置状态均未送电，载入标准接线也不会自动送电；任务自动验收会显式执行送电操作，并继续尊重断路器状态。

- SB1–SB8 按住鼠标压下，松开回弹。`COM1–NO1` 是常开组，`COM2–NC2` 是常闭组，两组公共端相互独立。
- SA1、SA2 为两档保持旋钮，点击旋转 90°；零位常闭组导通，工作位常开组导通。
- HL1–HL6 为 DC 24V 指示灯，`L` 为正端、`N` 为负端。按绿、红、黄、绿、红、黄显示，断线、反接、交流误接或电势冲突时不点亮，不模拟烧毁。
- 现有端子排 `24V+`、`24V-` 已连接柜内直流电源，受总电源控制，与交流零线独立。万用表同时显示交流、带正负号的直流电压；正负短接或交直流混接会报告电势冲突。
- 视角模式点击元件查看只读属性；仿真模式点击同时操作。左下角显示类型、适用的额定电压、当前状态、触点通断及端子锚点，电源控制区标记“柜内预接”。导线属性与器件属性互斥，错误提示仍可见。
- 切换模式、失去窗口焦点或打开文件窗口会释放瞬时按钮；旋钮和急停保持其位置，重置训练才复位。SB1–SB8 及总启动/总停止仅按压中心彩色部分，钥匙开关仅旋转上方钥匙本体，急停仅按压红色帽；金属外圈、锁孔面、底座和原连接点均保持固定。

验证控灯回路：`24V+ → SB1_COM1`，`SB1_NO1 → HL1_L`，`HL1_N → 24V-`。送电后按住 SB1，HL1 点亮，松开熄灭；将 SB1 的两端替换为 SA1 的常开触点即可验证旋钮保持控灯。

现有物理端子锚点及 `.cc3d` 标识保持不变；旧 `SB1/SB2.COM/NO` 名称兼容到各自第一组触点。旧存档如果依赖过去误合并的 `COM1/COM2`，需要补接实际导线。面板参数来自 `PanelDeviceCatalog`，界面不提供参数编辑。PLC 联动详见上方说明；中间继电器行为见下节。传感器和电磁阀不因此获得器件行为。

### 交流接触器 KM1–KM4

安装位 29–32 的四只交流接触器使用独立的 **AC 220V** 线圈和八组触点。界面按物理编号 KM1–KM4 显示，属性同时注明对应运行时编号 KMF、KM1、KMR、KM2，与上表及旧存档保持一致。

| 类型 | 端子对 | 失电时 | 吸合时 |
| --- | --- | --- | --- |

柜体背部安装位 111–113 的三只接触器依次对应 KM1–KM3（运行时 KMF、KM1、KMR），前后本体共用同一线圈和触点状态。背部共绑定 54 个已有本体连接点，属性同时显示背部端点（例如 `KMF.53`）和对应的正面端子排（例如 `DuanZiPai_3.KM1_53NO`）。端点位置、悬停名称及存档标识保持不变；背部本体端子沿用仅在电线模式显示的规则，跳线模式仍可点击本体查看原理图。从背部端子接线供电后，正面属性也会同步显示吸合状态。

切到柜体背部后，接线模式点击本体会在同一左侧浮窗显示“KM编号 · 背部接触器原理图”，保留正在绘制的导线。视角、仿真及排故模式点击背部本体均可查看只读属性；排故时点击端子优先选择仪表测点，查看本体不会改动已选测点，转速仪保留原有操作优先级。

接线模式点击本体，在与 KA 共用的左侧浮窗查看原理图。图纸由程序按参考图重绘，只保留黑色编号、KM 字样、触点、机械联动线和线圈符号，PNG 背景透明并显示在白底上。浮窗以 1920×1080 为基准宽 280、高 240，距左侧 16、顶部 140；标题字号 14、关闭按钮字号 12、图纸区域 264×196，随 Canvas 缩放并保持图纸比例。KA/KM/FR 切换复用同一窗口，查看或关闭图纸均保留接线起点和路径点；端子操作、导线节点拖动优先，窗口外可继续接线，点击空白或端子不收起图纸。

验证控灯：`V_1 → KM1_A1`、`N_1 → KM1_A2`，再接 `24V+ → KM1_53NO`、`KM1_54NO → HL1_L`、`HL1_N → 24V-`。开启总供电后接触器吸合、指示灯亮；断开 A1 的供电后释放、灯灭。正反转标准任务使用两只接触器的 61–62 常闭触点交叉互锁、13–14 常开触点自锁。规格由 `ContactorDefinition` 统一定义，吸合状态由电路求解重建，无需新增存档字段。

视角、仿真模式左键点击本体，右侧可滚动属性面板显示编号、位置、脱扣状态、五组回路实时通断和实际端子绑定；背部在排故模式也可查看，仪表端子优先。属性与 KA、KM、PLC、按钮及导线面板互斥。点击本体仅查看；仿真模式在属性面板使用“模拟脱扣”和“复位”按钮，其他模式按钮不可操作。三只独立脱扣与复位，载入接线或重置训练沿用原有状态重置规则，不增加存档字段。

### 转速表与变频测速

点击“排故”进入模式后，电机前端绿色轴头测点立即显示，无需先选择仪表或将鼠标悬停在测点上。选择“转速表”后，橙色三维表体跟随鼠标，将探头移到轴头，测点变亮后点击吸附，表内屏幕和仪表区同步显示该电机的实际转速。点击表体可拿起并换测其他电机；切换仪表会收回表体并保留绿色测点，退出排故或重置训练会一并隐藏测点。未接触显示 `—`，静止显示 `0 rpm`，反转显示转速绝对值。电机顶部六个接线柱不作为测速点。

G120 输入 `L1/L2/L3` 需要三相供电，输出 `U2/V2/W2` 经端子排、导线和闭合接触器接到电机 `U1/V1/W1` 后，电机按变频器实际输出转速运行。面板的 `P1120/P1121` 决定加减速过程；交换任意两根输出相线会改变方向。输出缺相、断电或变频器故障后电机滑行停转，默认 3 秒；现有制动状态默认 1 秒停转。输出短接、接地或与工频电源混接会停止有效驱动并提示故障。工频额定转速仍为 1450 rpm；本次未增加负载转矩及双速绕组模型。

三维表体复用原 `Tachymeter` 网格和贴图，可通过 Unity 菜单 `Electrical Sim > Build Tachometer Model` 重建预制体。截图与测试结果位于 `Build/Reports/tachometer-*`。

离散电气图以端口和导电关系为基础，每帧迭代到稳定状态，包含：

- 三相电源和相序；
- 断路器、熔断器；
- 常开/常闭按钮与触点；
- 接触器线圈、主触点、辅助触点、自锁和互锁；
- 时间继电器延时触点；
- 热继电器和过载状态；
- 电机正转、反转、停止与制动；
- 短路、断路和非法反转检查。

任务提交先比较规范化网络拓扑，再执行规定按钮序列验证接触器、保护器和电机行为，避免仅按线路数量评分。

## 本地考试与虚拟 PLC

- `F5`、`F6`、`F7`、`F8` 分别进入 A、B、C、D 本地考试包。

## `.cc3d` 兼容

element

## 本地数据

接线通过顶部“保存接线”保存为 `.cc3d` 文件。每次保存均可选择目录和文件名，覆盖已有文件时由文件窗口确认。文件夹按钮用于“打开接线”；打开后进入接线模式，可继续编辑节点、删除和新增导线。

当前接线有未保存修改时，打开前可选择“保存后打开”“放弃修改并打开”或“取消”。取消保存或保存失败会中止打开；文件损坏、缺失路径点、重复导线 ID 或端子不匹配不会清空当前接线。撤销回已保存状态后不再提示未保存修改。

接线默认目录是 `Application.persistentDataPath/Projects`，Windows 构建中通常为：

```text
%USERPROFILE%/AppData/LocalLow/同立方/电气控制系统仿真软件/Projects/
```

本次运行会记住最近成功使用的目录和文件名。存档仅包含已完成的导线及其路径、样式和柜面归属；未完成接线预览、相机视角、设备位置和运行状态不通过此功能恢复。空接线也可保存。

会话、考试等其他本地数据默认位置：

```text
文档/电气控制系统仿真软件/
```

该目录用于保存会话、考试进度、成绩、截图和录屏帧序列。接线的保存与打开使用系统本地文件选择窗口，无需网络。

## 离线边界

# 场景 PLC 与西门子实机联调

## 功能及准备

场景中的 PLC_1、PLC_2 分别可配置为 S7-1200 或 S7-1500，通过 S7 TCP 通信连接。
每台有 14 个数字量输入、10 个数字量输出。型号选择改变通信配置，不替换现有外观模型。

1. PC 与 PLC 接入可互通的以太网，确认 CPU 的真实 IP 地址。
2. 在 TIA Portal 的 CPU 属性中开放远程伙伴 PUT/GET 访问，并将硬件配置下载到 CPU。较新固件需要先按相应版本配置用户/运行权限。
3. 默认输入写入 M0.0～M1.5。将这些位预留给场景，避免与 PLC 程序其他用途、时钟存储器或系统存储器重叠。PLC 程序使用这些 M 位作为虚拟输入。
4. 输出默认读取 Q0.0～Q1.1。实际 CPU 或硬件配置不足以使用这些 Q 地址时，可逐点改为有效的 Q、M 或 DB 位。
5. 使用 DB 映射时，新建足够大小的非优化通信 DB，关闭其“优化的块访问”，下载该 DB，并填写绝对位地址，如 DB10.DBX0.0。

参考：[西门子 PUT/GET 说明](https://docs.tia.siemens.cloud/r/en-us/v21/s7-communication-s7-1200-s7-1500-s7-1200-g2/get-read-data-from-a-remote-cpu-s7-1200-s7-1500-s7-1200-g2)、[新固件 PUT/GET 访问配置](https://support.industry.siemens.com/cs/ww/en/view/109925755)。

## 属性操作

点击场景 PLC 本体，在右侧属性面板中配置：

| 属性 | 默认值 / 行为 |
| --- | --- |
| CPU 型号 | S7-1200；点击型号按钮切换 S7-1500 |
| IP | 留空，必须填写实际 IPv4 地址后连接 |
| TCP 端口 | 102 |
| Rack / Slot | 0 / 0，可按硬件配置修改 |
| 轮询周期 | 100 ms；范围 20～10000 ms，是每次通信完成后的等待时间 |
| 通信超时 | 2000 ms；范围 100～30000 ms，覆盖整个读写周期 |
| 输入映射 | M0.0～M1.5，可改为 M 或 DB 位；不允许重复写入位或写 Q 区 |
| 输出映射 | Q0.0～Q1.1，可改为 Q、M 或 DB 位 |

“保存属性”将编辑应用到当前工程；使用工程保存功能写入 `.cc3d` 文件。
“连接”会先校验并应用面板中的配置，随后连接并读取状态。连接过程中及连接成功后配置锁定。
“定位”以黄色球形标记指出原端子排的实际连接点；切换线型不会改变绑定关系。
面板的点位状态显示真实地址读取值。供电状态显示场景电路状态；Q 位为 1 且场景供电正确时才会导通场景输出。

## 电路与程序示例

场景 DC 24V 正极接 PLC 的 L+、3L+；负极接 M、1M、3M-。PE 保持保护接地语义，不与通信地址关联。
打开柜内总供电。将 SB1 的 COM1 接 DC 24V 正极，NO1 接 PLC_1_M0.0。
PLC_1_Q0.0 接 HL1 的 L，HL1 的 N 接 DC 24V 负极。

在专门的联调程序中可使用以下 SCL 语句：

```scl
// M0.0 是本场景写入的虚拟按钮输入；Q0.0 是程序计算后的输出。
%Q0.0 := %M0.0;
```

如需将结果放在专用通信 DB，可将场景输出映射改成对应 DB 位，再由 PLC 程序赋值。
程序不会直接写真实 I 区、强制真实 Q 区，也不下载程序或切换 CPU RUN/STOP。

切换到“仿真”模式后，按下虚拟 SB1，软件将状态写入 M0.0；CPU 执行程序后，软件读回 Q0.0，按实际接线驱动虚拟 HL1。
释放按钮后信号恢复为 0。移除输入公共端 1M，输入变为 0；移除本体或输出供电，场景 Q 输出不导通。

## 停止、故障与工程切换

- 非仿真模式只读监控；退出仿真时清除本连接已接管的虚拟输入位，场景输出立即断开。
- 主动断开、打开其他工程或禁用仿真控制器时，同样尝试清理已写入输入，然后释放连接。
- 通信故障后停止读写，清除场景输出状态，不自动重连。确认问题解决后点击“连接”。
- 断网情况下无法确认真实 PLC 的 M/DB 位是否已清零；场景显示的“输出已断开”仅指虚拟电路，真实 PLC 的停机/故障处理由其程序负责。
- 新旧 `.cc3d` 都可加载；旧文件使用默认 PLC 配置。工程打开后不自动连接。旧连接清理完成前不允许发起新连接。
- 两台场景 PLC 可以连接不同设备；连接到同一 CPU 时不允许使用重叠的输入写入地址。

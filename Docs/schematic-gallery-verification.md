# 六张原理图图册验证记录

## 交付内容

左侧原理图框改为独立图册，保留当前位置及向左收缩。顶部“原理图”控制图册显示；上一张、下一张循环切换，切换模式或收缩不改变当前页，重新启动恢复第一页。

六张 PNG 与附件逐文件 SHA-256 一致，保留完整内容与原始尺寸。Sprite 导入采用无压缩、关闭 mipmap、最大尺寸 2048。数据位于 `Assets/ElectricalSim/Resources/SchematicCatalog.asset`，图片位于同目录的 `Schematics/`。

点击缩略图或“放大”打开宽高各占屏幕 90% 的窗口。支持同步翻页、1～4 倍缩放、鼠标位置为中心的滚轮缩放、边界限制拖动、适应窗口及关闭。打开、翻页和改变窗口尺寸均重新居中适配；Esc 仅关闭大图。查看期间阻挡场景输入，保留接线草稿、模式和运行状态。

旧任务目录、标准接线、验收、考试控制器、F5～F8 入口、倒计时及考试专用打包资源已移除，原资源导入器同步排除旧图与考试资源。KA/KM/FR 器件图、自由接线、仿真、排故、接线存档、截图和录像继续保留，未删除用户已有存档。

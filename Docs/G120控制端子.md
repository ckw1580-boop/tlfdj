# G120 控制端子使用说明

本功能将附件《G120宏功能 (1).pdf》及 CU240E-2 端子图中的 32 个控制端子接入场景仿真。上、下端子排左侧分别新增 12、14 个接点，原有六个 DI 和其他器件接点的位置保留。首次进入场景使用宏 1。

## 布局与端子标识

新增接点占用最靠近原 G120 区域的连续空置端子模块，与旧区域留一个模块间隔；上排位于端子排上侧，下排位于下侧。点位按实际模块和原接点偏移生成，沿用绿色标记、端子拾取和电线模式。黄色 G120 区域备注覆盖新增位置。

| 位置 | 从左到右的新增端子 |
| --- | --- |
| 上排 `DuanZiPai_3` 左侧，12 点 | `1 +10V`、`2 0V`、`3 AI0+`、`4 AI0−`、`10 AI1+`、`11 AI1−`、`9 U24V`、`28 U0V`、`69 COM1`、`34 COM2`、`31 外部24V+`、`32 外部0V` |
| 下排 `DuanZiPai_4` 左侧，14 点 | `14 PTCA`、`15 PTCB`、`12 AO0+`、`13 AO0−`、`26 AO1+`、`27 AO1−`、`20 DO0 COM`、`19 DO0 NO`、`18 DO0 NC`、`22 DO1−`、`21 DO1+`、`25 DO2 COM`、`24 DO2 NO`、`23 DO2 NC` |

| 保留的原接点 | 标准端子号 | DI 公共端 |
| --- | --- | --- |
| `G120_DI0` | 5 | 69 COM1 |
| `G120_DI1` | 6 | 34 COM2 |
| `G120_DI2` | 7 | 69 COM1 |
| `G120_DI3` | 8 | 34 COM2 |
| `G120_DI4` | 16 | 69 COM1 |
| `G120_DI5` | 17 | 34 COM2 |

上排总端口数由 59 增至 71，下排由 48 增至 62。新增端口使用稳定名称，例如 `DuanZiPai_3.G120_T01`、`DuanZiPai_4.G120_T14`；标准逻辑节点分别为 `G120.T01`、`G120.T14`。悬停提示显示端子号和信号名，接线文件使用稳定端口标识。

原 `DI1_COM1`、`DI1_COM2` 分别作为 69、34 的兼容入口。原 `G120_A1` 的标识和导线保留，但它与 AI0 正负端均不连通。需要模拟量调速时，请把旧 A1 导线改接 `3 AI0+`，并另外接好 `4 AI0−` 的参考线。

## 打开属性和选择宏

在“视角”或“仿真”模式点击 G120 本体或端子排的 G120 区域，打开右侧属性面板。面板上方提供 AI/AO/PTC 设置，下方显示当前宏、控制及主电源状态、转速、故障、各端子规格、参考端、实时值和接线数量；使用滚轮查看完整内容。端子接线和仪表测点拾取优先于属性选择。

点击顶部“BOP 参数”进入原参数面板。修改宏时，先设置 `P0010=1`，再设置 `P0015`。当前可选宏为 `1、2、3、4、5、6、7、8、9、12、13、14、15、17、18、19、20、21`，包括固定转速、MOP、模拟量、点动、三线制和已有总线控制。宏切换后，属性面板中的 DI 功能随之更新，模拟调速来源重新选择 AI0。

“恢复默认”会清除运行状态、模拟输入及 PTC 测试状态，恢复宏 1。G120 的时间推进由场景仿真统一管理，每步只推进一次加减速和 MOP；接线变化引起的零时间求解不会额外推进转速。

## 宏 1 实际接线示例

使用已有开关或按钮控制 DI。以下端子号均指 G120 控制端子，不是主回路编号。

1. 在接线模式接齐 G120 主输入 `L1/L2/L3` 的三相电源；如需驱动电机，将 `U2/V2/W2` 通过现有端子排及主回路连接至电机。开启柜内供电。
2. 将 `28 U0V` 分别接到 `69 COM1` 和 `34 COM2`。默认没有这两根跳线，缺少对应公共端时该组 DI 不会有效。
3. 将 `9 U24V` 经正转开关接到 `5 DI0`，经反转开关接到 `6 DI1`。
4. 将 `9 U24V` 经转速选择开关分别接到 `16 DI4` 和 `17 DI5`。
5. 切换至仿真模式。只接通正转或反转中的一路，并至少接通一个转速选择信号。属性中可同时核对 DI 的 ON/OFF 和实际转速。
6. 需要故障复位时，将 `9 U24V` 经瞬时常开按钮接到 `7 DI2`。先排除故障原因，再按下按钮产生复位上升沿；也可点击属性面板的“故障复位”。

| 宏 1 输入 | 行为 |
| --- | --- |
| DI0 有效，DI1 无效 | 正转命令 |
| DI1 有效，DI0 无效 | 反转命令 |
| DI0、DI1 均无效或同时有效 | 不使能运行 |
| 只有 DI4 有效 | 使用 `P1003`，默认 300 rpm |
| 只有 DI5 有效 | 使用 `P1004`，默认 400 rpm |
| DI4、DI5 同时有效 | 两个转速相加，默认 700 rpm |
| DI4、DI5 均无效 | 速度给定为零 |
| DI2 从无效变为有效 | 故障复位命令 |
| DI3 | 宏 1 未分配 |

加减速遵循 `P1120/P1121`，给定同时受已有转速限制参数影响。其他宏的 DI 分配不同，例如宏 8/9 使用 DI1/DI2 升降 MOP、DI3 复位；宏 19/20 使用 DI0 作为停止许可、DI4 复位。接线前以当前宏属性说明为准。宏 14/15 的 DI1 为外部故障许可，断开会触发故障。

## 控制电源与数字输出

三相主输入正常，或者 `31 外部24V+` 与 `32 外部0V` 正确接入外部直流电源，都可使控制单元工作。外部输入接受 DC 18–30V；反接不提供有效控制电源。仅外部直流供电可以查看和测试控制信号，但不能驱动电机。

`1/2` 提供内部 10V，`9/28` 提供内部 24V；两者随控制供电变化。把内部 24V 回接到 31 不能使失电后的控制单元自行保持供电，31 也不作为向外供电的输出。DI 以实际接线的公共端为参考，18–30V 为有效电平。

| 输出 | 状态与触点 |
| --- | --- |
| DO0 故障 | 正常或控制失电：`20 COM–18 NC`；控制有电且故障：`20 COM–19 NO` |
| DO1 报警 | `21+ / 22−` 为有极性的晶体管开关，报警时按正向接法导通 |
| DO2 运行使能 | 未使能：`25 COM–23 NC`；主电源正常、无故障且运行使能：`25 COM–24 NO` |

DO 是开关输出，须另接负载电源，不会自动提供 24V。例如使用外部 24V 测试 DO0：正极接 20，19 经兼容的负载接电源负极，故障时常开支路接通；改接 18 可观察常闭支路。DO1 正向接法为外部正极经负载接 21，22 接负极。端子属性中的电压、电流规格是接口说明，当前模型不计算负载电流及器件发热。

## AI0、AI1 输入和标定

AI0 为 `3+/4−`，AI1 为 `10+/11−`；正负端必须分别接线，不能以导通关系合并。每路默认选择“实际接线”和 ±10V 输入。输入类型按钮依次切换 `0–10V`、`2–10V`、`0–20mA`、`4–20mA`、`±10V`；切换类型时恢复该类型的默认标定。

要使用属性注入，点击该路来源按钮切换到“模拟输入”，填写输入值，点击“应用输入与标定”。此时该路仅使用注入值，不与线路值相加；切回“实际接线”后恢复从正负端读取。填写数字时使用小数点，例如 `-5.5`。

四个标定字段定义两点：输入 `X1` 对应 `Y1%`，输入 `X2` 对应 `Y2%`。中间值按直线换算，X1 与 X2 不能相同。默认 ±10V 使用 `0V→0%`、`10V→100%`，因此负电压得到负百分比；是否以该符号控制方向还取决于所选宏。无参考、超量程、类型不匹配或冲突状态可在属性中读取，无效输入不给出有效调速量。

模拟量调速宏默认使用 AI0；点击“模拟调速来源”可选择 AI1。例如宏 12 下，接好 DI0 启动与 DI 公共端，再将 `1 +10V → 3 AI0+`、`2 0V → 4 AI0−`，即可提供默认标定下的 100% 给定。也可将 AI0 改为模拟输入并输入 5V，得到 50% 给定。

## AO0、AO1 输出和回接测试

| 输出 | 端子 | 默认信号和满量程 |
| --- | --- | --- |
| AO0 | `12+/13−` | 0–20mA；转速绝对值 1500 rpm 对应满量程 |
| AO1 | `26+/27−` | 0–20mA；“模拟电机电流”对应输出，默认 0A；满量程字段为 0 时使用电机额定电流 `P305` |

点击 AO 输出类型按钮可切换 0–20mA、0–10V、4–20mA。修改满量程或模拟电机电流后点击“应用输入与标定”。输出比例限制在零到满量程之间；4–20mA 模式的零反馈对应 4mA。AO1 的电流是用户输入的模拟值，不由电机负载计算。

回接示例：AO1 选择 0–20mA，AI1 也选择 0–20mA 且来源为实际接线；接 `26 → 10`、`27 → 11`。把 AO1 满量程设为 10A、模拟电机电流设为 5A 后应用，输出设定值为 10mA，AI1 默认标定显示 50%。也可把 AO0 接到匹配的 AI，观察转速反馈。

属性分别显示 AO 设定值、有效值和连接诊断。电流输出未接匹配接收端时显示开路；反接、输入输出类型不匹配和多源冲突会产生无效状态。0–10V 输出可以在开路时测量端电压。

## PTC 状态测试和复位

PTC 端子为 `14 PTCA / 15 PTCB`，监测默认关闭。在属性中点击“PTC 监测”启用，再点击状态按钮依次选择正常、过热、断线、短路。该设置代表模拟传感器状态，不需要新增器件；实际将 14、15 短接也会被判为短路。

控制单元有电且监测启用时，异常触发诊断并禁止有效驱动。恢复“正常”后，故障仍保持，需要点击“故障复位”或使用当前宏的复位 DI。持续异常不能通过复位命令清除。“恢复默认”会关闭监测并清除测试状态。

过热显示 `A07910 / F07011`，断线、短路测试显示 `A07015 / F07016`，可配合 DO0/DO1 验证故障和报警输出。诊断编号参照[西门子 CU240E-2 操作说明](https://support.industry.siemens.com/cs/attachments/94020562/G120_CU240BE2_BA6_0414_eng.pdf)。本状态测试直接触发诊断，不模拟传感器电阻、报警延时和热积累。

## 测量、存档与范围

万用表直流档支持内部 10V/24V、外部控制供电及模拟电压网络，读数为红表笔相对黑表笔的电压。缺少共同参考与电势冲突分别报告，不能把两个浮空参考端视为自动连接。模拟电流和 PTC 状态在 G120 属性中查看；未增加万用表电流档。

`.cc3d` 格式不变，保存新增端口上的导线及稳定端点，兼容原 DI、COM、A1 和主回路接线标识。新增导线使用现有删除、撤销和恢复流程。当前接线文件不保存 G120 宏与面板参数、AI/AO 测试设置、PTC 状态、模拟电机电流或运行状态；这些设置也不因保存动作而改变。重新进入场景或恢复默认后，从默认宏 1 重新配置。

本功能采用控制信号级仿真，数值电压和电流带有独立参考端；模拟信号正负端不会因为属于同一个信号而被短接。电机电流由用户设定，PTC 使用状态模拟；不包含负载动力学、热积累、真实变频波形或安全认证功能。宏中标注的安全功能为预留说明。

本说明描述当前功能和操作，不替代运行测试记录。端子定义参考用户附件及[西门子 CU240B-2/CU240E-2 操作说明](https://support.industry.siemens.com/cs/attachments/51410072/CU240B-2_CU240E-2_DRAFT_20110513_en.pdf)；DO 默认功能参考[西门子参数表](https://support.industry.siemens.com/cs/attachments/49946755/PLI_CU240BE_en_V44_012011.pdf)。

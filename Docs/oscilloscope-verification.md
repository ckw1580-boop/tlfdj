# 台式双通道差分示波器

入口：排故工具中的“示波器”。选择后显示世界空间中的台式仪器及右侧属性面板。

## 操作

- CH1 为黄色，CH2 为青色。每路各有正负探头，可分别接到两个端子；通道之间不共地。点击探头或对应输入插口拿起，点击端子连接。
- 拖动机身移动仪器，“仪器归位”返回本次选择时的位置。“收回全部探头”解除四个测点。
- 实体 RUN/STOP 和 AUTO 按钮分别冻结/恢复显示、自动量程；TIME/DIV 和两路 V/div 旋钮点击后循环档位。
- 右侧属性提供通道开关、AC/DC 耦合、电压档位、垂直位置、公共时基及恢复显示默认值。
- 停止只冻结测量画面及对应标签，不停止电路。冻结后仍可调整电压档位和垂直位置查看已捕获信号；耦合、时基及波形模式保留捕获时设置。恢复运行后读取当前接线。
- 切换工具或离开排故模式会收回探头；显示设置在当前场景保留，训练重置后恢复默认。

## 测量口径

当前工况曲线基于同一个仿真快照，横向 10 格、纵向 8 格。工频相对零线使用既有 220 V 有效值，线间使用既有 380 V 有效值，频率均为 50 Hz；通道保留三相相位关系。直流支持系统 24 V 和已有模拟电压网络。探头反接反转瞬时电压及直流极性。

DC 耦合保留直流分量，AC 耦合移除直流分量，不计算滤波瞬态。读数为当前耦合后的有效值、峰峰值、平均值和频率；直流频率显示“—”。自动量程仅考虑开启且有效的通道，无有效信号时保留设置。

测点缺失、参考不明确、电势/信号冲突和未收敛分别提示；无效通道不绘制曲线，也不影响另一通道。同网且无冲突时电压为零。变频输出通过独立的来源和相别元数据查询，不作为工频电源识别。

模型屏幕和右侧图共用采样数据；运行时最多刷新 30 次/秒，隐藏或弹窗屏蔽时不重新采样。探头和软线不进入电路，不更改接线、撤销记录或 `.cc3d` 文件。

## 资源与验证

### 变频输出（第二阶段）

G120 根据斜坡速度命令和 P310/P311 计算输出频率。基波线电压为 `P304 × min(f/P310,1)`，且不超过三相输入线电压。默认 25 Hz 为 190 V，50 Hz 以上为 380 V；电机使用同一输出描述的基波电压和频率。

`InverterVoltage` 是不可变快照值，包含来源、运行/有效状态、方向、频率、线电压、母线电压、相位和载波时刻。相位仅在求解时间步末推进一次；测量、拓扑迭代及 `Solve(0)` 不推进相位，旧快照保持独立，训练/工厂重置清除相位。输出来源沿实际网络根节点传播，读数通过 `SimulationSnapshot.ReadVoltage` 及电压 API 获取。

理想两电平桥采用 min/max 零序注入，固定 4 kHz 对称载波，中点参考计算每周期占空比；母线为输入线电压的 √2 倍，线间 PWM 只有 −Vdc、0、+Vdc。无整流动态、纹波、死区、器件压降、寄生、对地共模或停机反电动势模型。输出频率达到 2 kHz 时仍可测基波，PWM 提示超出教学范围；叠加仅绘制基波。

每通道默认叠加，可选基波/PWM；叠加中的基波为虚线，PWM 为阶梯线。801 点基波、开关边沿区间和 801 列极值共用同一捕获数据；宽时基按列保留 PWM 极值，放大时绘制精确边沿。自动量程以所选波形峰值调整电压档，公共时基按基波显示约两周期。峰峰值对应基波或 PWM；PWM 平均值明确标注为当前显示窗口的平均值。万用表交流档显示“变频基波”，直流档显示线间周期平均值（理想模型为零），通断档保留带电保护。验电笔测输出对系统参考显示“参考不明确”。

同源输出正常停机、断电、面板故障时为零；断线或跨独立参考提示参考不明确。短接、接地、工频/控制电源混接和多变频源混接停止对应驱动并标记冲突；无效通道清除曲线，其他通道不受影响。模式、相位和采样数据不写入 `.cc3d`。

新增 `InverterVoltageTests` 验证 V/f、PWM 基波积分误差、相位推进、快照独立、极性、故障、端子排/接触器传播及宽时基脉冲保留；G120 参数测试覆盖额定参数变化、输入电压限幅、斜坡命令和停机。场景测试覆盖双通道三种模式、缩放、共享数据、冻结和重置，并生成 `Logs/InverterWaveform/overlay.png` 与 `pwm-zoom.png`。

模型重建：`Electrical Sim > Build Oscilloscope Model`。预制体为 `Assets/ElectricalSim/Resources/Oscilloscope.prefab`，生成材质位于 `Assets/ElectricalSim/Generated/Oscilloscope`。

`OscilloscopeMeasurementTests` 验证有效值、相位、极性、参考隔离、模拟电压、异常状态和量程。`OscilloscopeSceneTests` 验证模型、四探头真实射线、拖动与锚点、界面控制、冻结、工具切换和模态屏蔽。应同时回归万用表、验电笔、转速表和重置确认测试。

不提供探头倍率、触发、历史录波和频谱分析。
